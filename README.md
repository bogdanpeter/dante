# DANTE – A professzionális audióhálózatok kézikönyve

Ez a repository a Markdown alapú kézikönyv forrását tartalmazza.

## Felépítés

- `chapters/` – fejezetek
- `diagrams/` – Mermaid és draw.io diagramok
- `images/` – képek
- `labs/` – laborfeladatok
- `appendix/` – függelék

A könyv fejezeteit a `SUMMARY.md` tartalomjegyzék követi.
